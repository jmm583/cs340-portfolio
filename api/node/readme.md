# NobleGoldFish API

## Getting Started
Run the command "npm install".

Run the command "npm run dev".

## Deployment to Production
Copy all files, excluding the node_modules folder and .env files, to the user classwork environment folder.

Run the cmd "npm install".

Create and update the .env file with the correct required values.

Run the cmd "npm run production".

## DotENV
Uses .env file to store communication details for the backend database. Required components and example values:

    DB_HOST = 'localhost'
    DB_USER = 'root'
    DB_PASSWORD = ''
    DB_Database = 'project'
    DB_PORT = 3306
    PORT = 6113
