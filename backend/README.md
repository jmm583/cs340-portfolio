# Backend Database


## Getting Started
The required sql code can be imported from the following:

DDl.sql -- Provides sample data and the load function which also acts as the reset sql.

PL.sql -- Provides all the CRUD sql stored procedures

Other sql files and purpose.

initial.sql -- Initial sql required to build the database from earlier steps. Not required for the app.

DML.sql -- Proposed CRUD queries from earlier steps. Not required for the app.

test_DML.sql -- Test scripts to ensure the DML.sql was correct. Not required for the app.
